# Regularization

## Description
This project explores various regularization techniques used in machine learning to prevent overfitting and improve the generalization of neural networks.

## Files
* **0-l2_reg_cost.py**: Function that calculates the cost of a neural network with L2 regularization.

## Requirements
* All files are interpreted/compiled on Ubuntu 20.04 LTS using `python3` (version 3.8)
* All files follow the `pycodestyle` style (version 2.5)
* All modules have documentation
* All functions have documentation
* All files are executable
