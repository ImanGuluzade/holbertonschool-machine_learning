# Optimization

This project folder contains various optimization techniques used in Machine Learning to improve model performance and speed up convergence.

## Learning Objectives
* What is a local optimum?
* What is a global optimum?
* How to normalize data.
* What is Stochastic Gradient Descent?
* What is Batch Gradient Descent?
* What is Mini-batch Gradient Descent?
* How to implement various optimization algorithms (Adam, RMSprop, etc.)

## Project Structure
| File | Description |
| --- | --- |
| `0-normalization.py` | Function to normalize a dataset |
| `1-moving_average.py` | Function to compute weighted moving averages |
| `2-update_variables_momentum.py` | Update variables using Gradient Descent with Momentum |
| `3-batch_norm.py` | Function to implement Batch Normalization |
