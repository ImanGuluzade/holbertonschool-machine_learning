# Transfer Learning

This directory contains projects and tasks focused on **Transfer Learning** architectures. It explores utilizing pre-trained state-of-the-art computer vision models (such as ResNet, VGG, or Inception) to solve new classification problems efficiently without training networks completely from scratch.
