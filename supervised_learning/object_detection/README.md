# Object Detection

This directory contains projects and exercises focused on object detection algorithms and architectures within the Supervised Learning curriculum.

## Description
Object detection combines image classification and object localization to identify what objects are present in an image and determine their precise location using bounding boxes. This section explores modern computer vision models, their loss functions, and evaluation metrics.

## Key Concepts covered
* **Bounding Boxes & Anchor Boxes**
* **Intersection over Union (IoU)**
* **Non-max Suppression**
* **YOLO (You Only Look Once)** architecture and regression-based detection

## Requirements
* Python 3.5+
* TensorFlow 2.x
* NumPy
