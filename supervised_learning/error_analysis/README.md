# Error Analysis

## Description
This project focuses on evaluating the performance of machine learning models using various metrics. In supervised learning, simply knowing the accuracy isn't enough; we need to identify which classes are being confused and calculate specific metrics to tune the model effectively.

## Concepts Covered
* **Confusion Matrix:** Visualizing true positives, false positives, and false negatives.
* **Sensitivity (Recall):** The ability of the model to find all the relevant cases.
* **Specificity:** The ability of the model to identify negative results.
* **Precision:** The accuracy of the positive predictions.
* **F1 Score:** The harmonic mean of precision and recall.

## Learning Objectives
- How to create and interpret a confusion matrix.
- How to calculate mathematical metrics from raw prediction data.
- Identifying bias and variance within model errors.
