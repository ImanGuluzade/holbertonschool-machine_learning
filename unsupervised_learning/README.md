# 0x00. Dimensionality Reduction

## Description
This project covers dimensionality reduction in unsupervised learning,
starting with Principal Component Analysis (PCA) using NumPy.

## Learning Objectives
- What eigenvalues and eigenvectors are
- What the covariance matrix is
- What dimensionality reduction is and why it is used
- What PCA is and how it works
- How to maintain a fraction of the variance of a dataset

## Requirements
- Ubuntu 20.04 LTS
- Python 3.9
- NumPy 1.25.2
- Code follows the `pycodestyle` style (version 2.11.1)
- All files are executable
- All files end with a new line
- All modules, classes, and functions have documentation

## Files

| File | Description |
|------|-------------|
| `0-pca.py` | `def pca(X, var=0.95)`: performs PCA on a dataset and returns the weights matrix `W` of shape `(d, nd)` that maintains `var` fraction of the variance of `X` |

## Usage
```bash
./0-main.py
```
